Sw 4001.03 Prize Pool

Effective 2008-05-31.

Sw 4001.03 Prize Pool. (a) The prize pool for all prize categories shall consist of 50 per cent of each drawing period's sales, after the prize reserve accounts are funded to the amounts set by MUSL. (b) Tickets containing the following number of matches in a single lettered game play, irrespective of drawing order, shall have the prize amount awarded as indicated for a one dollar bet as shown in Table 3.1.1 below: TABLE 3.1.1 Expected Prize Payout Percentage Match | Prize | Percent of Prize Pool 5 of first set plus 1 of second set | Grand prize | 52.5763% 5 of first set and none of second set | $10,000.00 | 3.2909% 4 of first set plus 1 of second set | 500.00 | 1.5540% 4 of first set and none of second set | 50.00 | 2.7972% 3 of first set plus 1 of second set | 50.00 | 5.1283% 3 of first set and none of second set | 4.00 | 7.3847% 2 of first set plus 1 of second set | 4.00 | 4.3761% 1 of first set plus 1 of second set | 3.00 | 12.7181% 0 of first set plus 1 of second set | 2.00 | 10.1745% (c) In circumstances where the prize payout exceeds available dollars in the prize pool, the set prize shall be paid on a pari-mutuel basis. (d) If the grand prize is not won in a drawing, the prize money allocated for the grand prize shall roll over and be added to the grand prize pool for the following drawing.
