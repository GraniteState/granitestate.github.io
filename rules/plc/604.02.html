Plc 604.02 Additional Documentation Required for Initial Apprentice License Application

Effective 2026-09-21. Expires 2036-09-21.

Plc 604.02 Additional Documentation Required for Initial Apprentice License Application. In addition to the documentation required by Plc 304.04, an applicant for an initial apprentice license shall complete and submit an “Addendum to the Universal Application for Initial Licensure for Body Art Apprentices” dated 9/2026, and provide the following: (a) The applicant’s name as it appears on the “Universal Application for Initial Licensure”; and (b) The name, license number, mailing address, including city, state, and zip code, and telephone number of the qualified supervisor offering the apprenticeship program. Source. (See Revision Note #1 at chapter heading for Plc 600) #12622, eff 9-21-18 (formerly Plc 401.05); ss by #14631, eff 9-21-26, EXPIRES: 9-21-36 (formerly Plc 601.05)
