Saf-C 7505.03 Failure to File Accident Report

Effective 2024-04-24. Earlier expiration 2005-03-24.

Saf-C 7505.03 Failure to File Accident Report. If a person fails to file an accident report as required under RSA 264:3 and RSA 264:25, the financial responsibility administrator shall forward or cause to be forwarded by first class mail a notice of suspension of license and registration to the person’s last known address.
