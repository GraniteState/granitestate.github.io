Spe 604.04 The Board’s Renewal Application Processing Procedures

Effective 2016-07-09.

Spe 604.04 The Board’s Renewal Application Processing Procedures. The board's procedures for processing applications for renewal of certification shall be the same procedures as those described in Spe 402.07 for the processing of applications for renewal of licensure. Source. #9711, eff 5-8-10; ss by #11138, eff 7-9-16
