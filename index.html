GraniteState

A static knowledge base of New Hampshire places, the 2022–2032 districts, the election statutes, and the administrative rules, published for people and for agents.

Read it

  • AGENTS.md — how to look up a town, a district, or an RSA section
  • Revised Statutes — election law, with a page and a JSON-LD file for each section
  • Administrative rules — the Office of Legislative Services compilation, linked to the RSA sections it implements
  • rsa/index.json — RSA titles, chapters, and section addresses
  • kb/index.json — scheme URIs and concept counts
  • kb/names.json — names, aliases, GEOIDs, and GRANIT town ids
  • kb/context.jsonld — JSON-LD context
  • kb/vocab.jsonld — project vocabulary
  • kb/schemes/places.jsonld — state, counties, municipalities, and wards
  • kb/schemes/districts-2022.jsonld — 2022–2032 districts and plans
  • kb/KNOWN_GAPS.md — values that were not guessed
  • README.md — what this site is and how to rebuild it

One concept

Identifiers have no file suffix. The file is the same path with .jsonld added. Alton is kb/places/3300101060.jsonld. Laconia Ward 1 is kb/places/3300140180/ward-1.jsonld. Belknap 7 is kb/districts/2022/nh-house/belknap-7.jsonld.

Sources
